# مهاجریار — سامانه هوشمند انتخاب مسیر مهاجرت

**مهاجریار** یک سامانه‌ی کامل، شفاف و آفلاین‌پذیر برای ارزیابی مسیرهای مهاجرت است. کاربر پروفایل جامع خود را در یک ویزارد شش‌مرحله‌ای وارد می‌کند و سامانه ۱۲ مسیر مهاجرتی در ۷ کشور را با قوانین رسمی ۲۰۲۶ می‌سنجد: امتیاز، شکاف‌ها، هزینه‌ی تقریبی، زمان‌بندی، نقشه‌ی راه و چک‌لیست مدارک.

> این ابزار جایگزین مشاور حقوقی یا بررسی سفارت نیست. تمام اعداد و آستانه‌ها با تاریخ «آخرین بازبینی» و پیوند منبع رسمی نمایش داده می‌شوند و پیش از هر اقدام باید در صفحه‌ی رسمی کشور مقصد دوباره بررسی شوند.

## ساختار جامع داده (پروفایل)

فرم و مدل داده در `app/schemas.py` و `app/forms.py` پیاده شده‌اند و شامل این دسته‌هاست:

- **هویت و وضعیت پایه:** نام، ملیت، کشور اقامت، تاریخ تولد، وضعیت تأهل، همراهی همسر، تعداد فرزندان
- **تحصیلات:** مقطع، رشته، کشور تحصیل، سال فارغ‌التحصیلی، ECA، وضعیت شناسایی مدرک (ANABIN)، سطح NZQA
- **زبان:** انگلیسی (سطح + آیلتس تفکیکی)، آلمانی، فرانسه (سطح + آزمون)
- **سابقه‌ی کاری:** عنوان و کد شغل، کمبود نیرو، سابقه‌ی کل و ۵/۷/۱۰ سال، سابقه‌ی کانادا/استرالیا/نیوزیلند، ارزیابی مهارت، سال‌های ثبت حرفه‌ای
- **پیشنهاد شغلی:** کشور، حقوق، ارز، حامی شناخته‌شده، مدت قرارداد، مضرب میانه‌ی دستمزد، نرخ رایج، کمبود نیرو
- **مالی و خانواده:** پس‌انداز، درآمد ماهانه، درآمد غیرکاری، دورکاری، تحصیل و زبان همسر، سابقه‌ی همسر در کانادا، بستگان و اقامت قبلی
- **ترجیحات:** کشورهای هدف، اولویت‌ها (سرعت، هزینه، اقامت دائم، شهروندی، خانواده، بازار کار، زبان)، سقف بودجه
- **مدارک:** گذرنامه، شناسنامه، ریزنمرات، مدرک زبان، نامه‌های کار، سوءپیشینه، معاینات پزشکی، تمکن مالی، سند ازدواج، ECA

## معماری

```text
mohajeryar/
├── app/
│   ├── main.py            # FastAPI: صفحات HTML + API JSON + PWA + امنیت
│   ├── schemas.py         # مدل جامع پروفایل و خروجی‌ها (Pydantic v2)
│   ├── forms.py           # تحلیل فرم و پیام‌های خطای فارسی
│   ├── db.py              # SQLite (پروفایل‌ها و ارزیابی‌ها)
│   ├── ai.py              # مشاور اختیاری Groq + پاسخ قطعی جایگزین
│   ├── formatting.py      # اعداد، پول و تاریخ شمسی فارسی
│   ├── engine/
│   │   ├── base.py        # ساخت نتیجه، هزینه‌ها، آمادگی
│   │   ├── canada.py      # CRS + FSW + تغییرات ۳ نوامبر ۲۰۲۶
│   │   ├── germany.py     # کارت آبی + کارت فرصت
│   │   ├── netherlands.py # HSM + کارت آبی
│   │   ├── uk.py          # Skilled Worker
│   │   ├── australia.py   # 189/190/491
│   │   ├── newzealand.py  # SMC
│   │   ├── portugal.py    # D7/D8
│   │   ├── registry.py    # ثبت ۱۲ برنامه
│   │   └── advisor.py     # رتبه‌بندی، نقشه‌ی راه، چک‌لیست، روایت
│   ├── rules/programs.json# قوانین، هزینه‌ها، منابع و تاریخ بازبینی
│   ├── templates/         # Jinja2 راست‌به‌چپ
│   └── static/            # CSS، JS، فونت وزیرمتن، آیکون‌ها، Service Worker
├── tests/                 # ۵۳ آزمون موتور و API
├── mobile/android/        # پوستهٔ بومی Android/WebView
├── install.sh / install.bat
└── Dockerfile
```

- **موتور قطعی:** همه‌ی امتیازها، آستانه‌ها و شکاف‌ها بدون هوش مصنوعی محاسبه می‌شوند.
- **هوش مصنوعی اختیاری:** فقط برای پاسخ‌دادن به پرسش‌های آزاد روی دادهٔ همان ارزیابی؛ بدون کلید هم همه‌چیز کار می‌کند.
- **PWA:** نصب روی موبایل/دسکتاپ، کش پوسته و آخرین نتایج برای مشاهدهٔ آفلاین.
- **حریم خصوصی:** داده‌ها روی همان سرور/دستگاه شما در SQLite می‌مانند؛ هیچ ردیابی بیرونی وجود ندارد و CSP منابع خارجی را مسدود می‌کند.

## اجرا

### نصب یک‌مرحله‌ای (Linux / macOS)

```bash
./install.sh          # ساخت محیط مجازی و نصب وابستگی‌ها
./run.sh              # اجرای برنامه روی http://127.0.0.1:8000
```

### Windows

```bat
install.bat
run.bat
```

### Docker

```bash
docker compose up --build
```

### اجرای دستی

```bash
cd mohajeryar
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
.venv/bin/uvicorn app.main:app --host 0.0.0.0 --port 8000
```

سپس <http://127.0.0.1:8000> را باز کنید. مستندات API در `/api/docs` است.

### متغیرهای محیطی

| متغیر | پیش‌فرض | کاربرد |
| --- | --- | --- |
| `DATABASE_PATH` | `mohajeryar/data/mohajeryar.db` | مسیر پایگاه‌داده SQLite |
| `GROQ_API_KEY` | — | فعال‌سازی مشاور هوشمند |
| `AI_MODEL` | `llama-3.3-70b-versatile` | مدل Groq |
| `AI_ENABLED` | `1` | خاموش‌کردن کامل AI |
| `APP_ENV` | `development` | `production` سخت‌گیری امنیتی را بیشتر می‌کند |
| `ENFORCE_ORIGIN` | `0` | اجبار Origin برای درخواست‌های تغییردهنده |

## آزمون

```bash
cd mohajeryar
../.venv/bin/python -m pytest -q
```

پوشش آزمون: رندر همهٔ صفحه‌ها، همهٔ ۱۲ برنامه، مسیر ۴۲۲ اعتبارسنجی، چرخهٔ پروفایل (ایجاد/ویرایش/ارزیابی مجدد/حذف)، API، سرصفحه‌های امنیتی، آستانه‌های آلمان/هلند/بریتانیا/استرالیا/نیوزیلند/پرتغال و تغییرات زمان‌دار کانادا.

## نسخهٔ اندروید (APK)

پوستهٔ بومی در `mobile/android` قرار دارد. برنامه در اولین اجرا آدرس سرور مهاجریار را می‌پرسد، اتصال را با `/api/health` می‌سنجد و آن را ذخیره می‌کند؛ بنابراین یک APK برای هر استقرار (سرور شخصی، LAN یا دامنهٔ عمومی) کار می‌کند.

ساخت خودکار: workflow «Build Mohajeryar APK» در `.github/workflows/mohajeryar-apk.yml` که APK را می‌سازد و در Release با برچسب `apk-mohajeryar` منتشر می‌کند.

ساخت محلی (نیازمند JDK 17 و Android SDK 35):

```bash
gradle -p mobile/android assembleDebug
```

## استقرار

- `render.yaml` برای Render (پلن رایگان، دیسک پایدار برای SQLite)
- `Dockerfile` و `docker-compose.yml` برای هر سروری

پس از استقرار، همان آدرس را در APK وارد کنید یا با مرورگر «افزودن به صفحهٔ اصلی» را بزنید تا نسخهٔ PWA نصب شود.
