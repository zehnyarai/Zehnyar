# نسخهٔ اندروید مهاجریار

این پوشه یک پوستهٔ بومی Android/WebView برای «مهاجریار» است. یک APK برای همهٔ استقرارها: کاربر در نخستین اجرا آدرس سرور (دامنهٔ عمومی، سرور شخصی یا شبکهٔ محلی) را وارد می‌کند، برنامه با `/api/health` اتصال را می‌سنجد و آن را ذخیره می‌کند.

## رفتار

- **راه‌اندازی یک‌باره:** صفحهٔ `assets/index.html` آدرس سرور را می‌گیرد، اعتبار آن را بررسی می‌کند و در `SharedPreferences` ذخیره می‌کند.
- **خطای شبکه:** اگر صفحهٔ اصلی بارگذاری نشود، `assets/offline.html` با دکمهٔ «تلاش دوباره» و «تغییر آدرس سرور» نمایش داده می‌شود.
- **پیوندهای خارجی:** لینک‌های خارج از دامنهٔ سرور در مرورگر سیستم باز می‌شوند.
- **حریم خصوصی:** برنامه هیچ مجوز حساسی (مخاطبین، موقعیت، دوربین، حافظه) نمی‌خواهد؛ فقط `INTERNET`.
- **شناسهٔ نصب:** `ai.mohajeryar.app` — مستقل از نسخه‌های قبلی خانوادهٔ ذهنیار تا نصب هم‌زمان ممکن باشد.

## ساخت محلی

نیازمند JDK 17 و Android SDK با API 35:

```bash
gradle -p mobile/android assembleDebug
```

خروجی:

```text
mobile/android/app/build/outputs/apk/debug/app-debug.apk
```

## ساخت خودکار

Workflow «Build Mohajeryar APK» (`.github/workflows/mohajeryar-apk.yml`) با هر تغییر در `mohajeryar/mobile/**` اجرا می‌شود، APK را می‌سازد و در Release با برچسب `apk-mohajeryar` می‌گذارد. اجرای دستی:

```bash
gh workflow run mohajeryar-apk.yml
```

## نصب

1. APK را از بخش Releases دانلود کنید (یا artifact اکشن).
2. «نصب از منابع نامشخص» را برای این فایل مجاز کنید.
3. پس از باز کردن، آدرس سرور مهاجریار را وارد کنید.

> APK دیباگ برای استفادهٔ شخصی و آزمون است. برای انتشار در فروشگاه، کلید امضا و نسخهٔ release جداگانه لازم است.
