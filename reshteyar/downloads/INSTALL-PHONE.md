# نصب رشته‌یار روی گوشی اندروید

رشته‌یار یک **برنامه‌ی وب (PWA)** است. روی گوشی مثل اپ نصب می‌شود (آیکون روی صفحه‌ی اصلی، تمام‌صفحه، با کش فایل‌های ایستا)، اما فایل APK نیست و از گوگل‌پلی نصب نمی‌شود.

## ۱. اجرای سایت روی یک آدرس HTTPS
نصب روی گوشی فقط از آدرس `https://` امکان‌پذیر است. این فایل را روی یک سرویس میزبانی Python مثل Render، Railway یا یک VPS اجرا کنید:

```bash
cd reshteyar
pip install -r requirements.txt
cp .env.example .env   # مقادیر را ویرایش کنید
APP_ENV=production PUBLIC_BASE_URL=https://your-domain.ir ADMIN_PASSWORD=<رمز ۱۲+ کاراکتری> \
  uvicorn app.main:app --host 0.0.0.0 --port 8000
```

در production: `ALLOW_MOCK_PAYMENTS=0` باشد، `PUBLIC_BASE_URL` با `https://` شروع شود و رمز مدیر حداقل ۱۲ کاراکتر باشد. در غیر این صورت برنامه عمداً بالا نمی‌آید.

## ۲. نصب روی اندروید (Chrome)
1. آدرس `https://your-domain.ir` را در **Chrome** باز کنید.
2. دکمه‌ی **«نصب رشته‌یار روی گوشی»** پایین صفحه را بزنید، یا از منوی ⋮ گزینه‌ی **«نصب برنامه»** یا **«افزودن به صفحه‌ی اصلی»** را انتخاب کنید.
3. آیکون رشته‌یار روی صفحه‌ی اصلی گوشی ساخته می‌شود؛ از همان‌جا باز کنید.

## ۳. نکته‌ها
- پرداخت واقعی زرین‌پال فقط با مرچنت‌کد معتبر فعال می‌شود.
- نتایج تحلیل تخمینی است؛ مرجع نهایی همیشه دفترچه‌ی رسمی سازمان سنجش است.
