# رشته‌یار

راهنمای تحلیلی و تخمینی **انتخاب رشته‌ی کنکور** برای داوطلبان ایرانی، با فهرست کامل دانشگاه‌ها و رشته‌ها، شش گروه آزمایشی، و پرداخت اشتراک به **تومان**.

> این ابزار جایگزین دفترچه‌ی رسمی سازمان سنجش نیست. نمره‌ی نشان‌داده‌شده تخمینی است و تضمین قبولی نمی‌دهد.

## امکانات

- **صفحه‌ی هر گروه** (ریاضی، تجربی، انسانی، هنر، زبان، معارف):
  - ماشین‌حساب تخمینی با: معدل، درصد و ضریب هر درس، رتبه‌ی کل، رتبه‌ی با سهمیه، نوع سهمیه، استان، مقطع، نوع دانشگاه و علاقه‌مندی‌ها
  - فهرست رشته‌های گروه (جستجو و فیلتر مقطع) و دانشگاه‌های مرتبط (تخصصی یا عمومی)
  - عوامل مؤثر و نکات مخصوص گروه
- **فهرست کامل رشته‌ها** (۱۱۹۲ رشته) و **فهرست کامل دانشگاه‌ها و موسسات** (حدود ۲۹۰۰ مورد) با جستجو و فیلتر
- **صفحه‌ی عوامل مؤثر**: همه‌ی عواملی که روی انتخاب رشته و قبولی اثر دارند، با دلیل اهمیت و محل پیدا کردن آن
- **پرمیوم** با پرداخت به تومان:
  - نسخه‌ی رایگان: ۵ مورد اول هر فهرست
  - اشتراک: نمایش کامل، شانس قبولی (وقتی داده‌ی رتبه‌ها بارگذاری شده باشد)، گزارش قابل چاپ
  - پس از پرداخت، کد فعال‌سازی صادر می‌شود و در «حساب من» قابل استفاده است
- **پنل مدیریت** (`/admin`): آمار فروش و درآمد، فهرست پرداخت‌ها، بارگذاری CSV رتبه‌های قبولی

## ساختار

│   ├── scoring.py       # محاسبه‌ی نمره، پیشنهاد رشته/دانشگاه، شانس قبولی

## اجرای محلی

```bash
cd reshteyar
python3 -m venv .venv
source .venv/bin/activate            # ویندوز: .venv\Scripts\activate
pip install -r requirements-dev.txt
uvicorn app.main:app --reload --host 0.0.0.0 --port 8000
```

سپس به آدرس `http://localhost:8000` بروید. بدون تنظیم مرچنت، پرداخت در **حالت آزمایشی** است و هیچ پولی جابه‌جا نمی‌شود.

آزمایش‌ها:

```bash
pytest -q
```

## تنظیمات

همه‌ی تنظیمات با متغیر محیطی یا فایل `.env` تعیین می‌شوند (نمونه در `.env.example`).

| متغیر | توضیح |
|---|---|
| `APP_ENV` | `production` پرداخت آزمایشی را خاموش می‌کند |
| `PUBLIC_BASE_URL` | آدرس عمومی سایت؛ callback زرین‌پال: `<PUBLIC_BASE_URL>/premium/callback` |
| `DATABASE_PATH` | مسیر SQLite (در استقرار ابری روی دیسک پایدار) |
| `ZARINPAL_MERCHANT_ID` | مرچنت‌کد ۳۶ کاراکتری زرین‌پال |
| `ZARINPAL_SANDBOX` | `1` = محیط آزمایشی زرین‌پال، `0` = درگاه واقعی |
| `ALLOW_MOCK_PAYMENTS` | فقط برای تست؛ در فروش واقعی `0` بماند |
| `ADMIN_USER` / `ADMIN_PASSWORD` | ورود به `/admin`؛ اگر خالی باشد پنل غیرفعال است |
| `FREE_RESULTS_LIMIT` | تعداد موارد نمایش‌داده‌شده در نسخه‌ی رایگان (پیش‌فرض ۵) |
| `COOKIE_SECURE` | در HTTPS یک بگذارید |
| `CUTOFFS_PATH` | مسیر فایل رتبه‌های قبولی (پیش‌فرض `data/cutoffs.csv`) |

## پرداخت با زرین‌پال

1. مرچنت‌کد را در `ZARINPAL_MERCHANT_ID` قرار دهید.
2. برای تست، `ZARINPAL_SANDBOX=1` بگذارید (محیط `sandbox.zarinpal.com`).
3. آدرس `PUBLIC_BASE_URL` را برابر آدرس عمومی سایت قرار دهید؛ همان آدرس را در پنل زرین‌پال به‌عنوان callback ثبت کنید.
4. جریان پرداخت: ثبت سفارش در دیتابیس ← درخواست به `payment.zarinpal.com/pg/v4/payment/request.json` (مبلغ به ریال، یعنی تومان × ۱۰) ← انتقال کاربر به `StartPay` ← بازگشت به `/premium/callback` ← تأیید با `verify.json`.
   - مبلغ تأیید از دیتابیس خوانده می‌شود، نه از پارامترهای بازگشتی.
   - کد `101` (قبلاً تأیید شده) موفق حساب می‌شود و callback تکراری کد جدیدی نمی‌سازد.
5. برای فروش واقعی، `ZARINPAL_SANDBOX=0` و `APP_ENV=production` بگذارید.

> **توجه:** در محیط سندباکس نمی‌توان پرداخت واقعی زرین‌پال را آزمود. برای آزمون کامل، مرچنت‌کد واقعی لازم است.

قیمت‌ها در `data/plans.json` (به تومان) تنظیم می‌شوند. مقادیر فعلی **نمونه** هستند.

## داده‌ها و به‌روزرسانی

- فهرست‌ها با `scripts/build_data.py` از مخزن‌های GitHub ساخته می‌شوند. این اسکریپت به `codeload.github.com` دسترسی دارد. برای اجرای آفلاین از کش `scripts/.cache` استفاده کنید (`--offline`).
- نگاشت رشته به گروه و دانشگاه به گروه با قاعده‌های نام انجام می‌شود و **تقریبی** است.
- رتبه‌های قبولی را از پنل مدیریت یا با قرار دادن فایل `data/cutoffs.csv` وارد کنید. ستون‌ها:

```csv
year,group,university,field,quota,last_rank[,capacity]
1404,ریاضی,دانشگاه نمونه,مهندسی برق,none,12000,20
```

- `group` می‌تواند slug (`riazi`) یا نام داده (`ریاضی`) باشد.
- `quota` از کلیدهای `none, martyr, basij, local, disabled, needy, other` یا عنوان فارسی آن‌ها استفاده کند.
- داده‌ی رتبه‌ها **در این مخزن نیست**. بدون آن، بخش شانس قبولی نمایش داده نمی‌شود و پیام «داده‌ی رتبه‌ها بارگذاری نشده است» نشان داده می‌شود.
- منطق شانس: اگر رتبه ≤ ۸۵٪ آخرین رتبه: بالا؛ ≤ ۱۰۰٪: متوسط؛ ≤ ۱۱۵٪: رقابتی؛ بیشتر: پایین.

## استقرار

- ریشه‌ی سرویس را `reshteyar/` قرار دهید (سرویس جداگانه از `main.py` ریشه‌ی مخزن).
- Build: `pip install -r requirements.txt`
- Start: `uvicorn app.main:app --host 0.0.0.0 --port $PORT`
- **دیسک پایدار** برای `DATABASE_PATH` لازم است؛ در غیر این صورت پرداخت‌ها و کدها با هر استقرار از بین می‌روند.
- متغیرهای `.env.example` را در محیط سرویس تنظیم کنید. `APP_ENV=production` و `ALLOW_MOCK_PAYMENTS=0` را فراموش نکنید.

## هشدارها و محدودیت‌ها

- **ماشین‌حساب تخمینی است.** سازمان سنجش نمره‌ی تراز را مبنا قرار می‌دهد. دفترچه‌ی همان سال مرجع نهایی است.
- **منابع داده GitHub و بدون مجوز صریح‌اند.** پیش از فروش تجاری، مجوز را بررسی کنید یا داده‌ها را از منابع رسمی بازسازی کنید.
- **رشته‌های پزشکی** (۱۶ مورد) به‌صورت دستی افزوده شده‌اند و باید با دفترچه تطبیق داده شوند.
- **ضرایب گروه معارف تأیید نشده است.** سهم‌بندی آن (۶۰٪ سوابق / ۴۰٪ آزمون) فرض است و نتیجه‌ی آن تقریبی است.
- **ضرایب ۱۴۰۴** از منابع خبری و آموزشی ثانویه گرفته شده‌اند؛ هر سال باید به‌روز شوند.
- **رتبه‌های قبولی** در مخزن نیست؛ باید از منبع رسمی تهیه و بارگذاری شود.
- **متن‌های حقوقی** (شرایط استفاده، حریم خصوصی، سیاست بازگشت وجه) باید توسط صاحب سامانه تدوین شود. متن‌های موجود راهنمای عمومی‌اند و مشاوره‌ی حقوقی نیستند.
- **مجوز کد** هنوز تعیین نشده است.
