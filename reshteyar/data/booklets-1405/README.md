# فهرست دانشگاه‌ها و رشته‌ها — دفترچه‌های انتخاب رشته ۱۴۰۵ (گروه‌های آزمایشی)

منبع: دفترچه‌های راهنمای انتخاب رشته ۱۴۰۵ (گروه‌های ریاضی و فنی، علوم تجربی، علوم انسانی، هنر، زبان‌های خارجی)
که از سوی سازمان سنجش منتشر شده‌اند (فایل‌های PDF روی همین شاخه در `reshteyar/` قرار دارند).

فایل `groups_1405.json` ساختار زیر دارد:
- `rows`: تعداد ردیف‌های کدرشته‌محل شناسایی‌شده
- `universities`: فهرست دانشگاه‌ها/پردیس‌ها با تعداد ردیف‌ها
- `fields`: فهرست رشته‌ها با تعداد ردیف‌ها

## محدودیت‌های شناخته‌شده
- این فهرست از متن PDF استخراج شده و هنوز بازبینی دستی نشده است.
- نام بعضی دانشگاه‌ها ممکن است به‌صورت‌های مختلف نوشته شده باشد (مثلاً با یا بدون خط تیره).
- بعضی ردیف‌ها دانشگاه مشخصی ندارند و با نام «(نامشخص)» آمده‌اند.
- جدول اصلاحات ۱۴۰۵ (اصلاحیه‌های ۱۶، ۱۸ و ۱۹ مهر) در این فهرست اعمال نشده است.
