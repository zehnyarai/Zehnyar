**فایل نصبی اندروید ویزایار** / Visayar signed universal APK

- بسته: `ai.visayar.app` · نسخه ۲٫۲٫۰ (کد نسخه ۲۳)
- همه معماری‌ها در یک فایل: arm64-v8a، armeabi-v7a، x86، x86_64
- فونت وزیرمتن و کل بانک اطلاعاتی داخل باندل؛ دو ارزیابی آفلاین رایگان
- نرخ مصوب: هر ارزیابی اضافه ۶۰۰٬۰۰۰ تومان؛ پنل رسید و اعتبار آماده است
- خرید آنلاین تا استقرار API روی دامنهٔ HTTPS و تنظیم نشانی آن در برنامه غیرفعال می‌ماند
- آمادهٔ نصب مستقیم؛ انتشار فروشگاهی به کلید امضای پایدار و انطباق پرداخت نیاز دارد

**نصب:** فایل APK را روی گوشی کپی کنید، اگر پیام «نصب از منابع ناشناس» آمد اجازه نصب را بدهید و فایل را باز کنید.

**Install:** copy the APK to the phone, allow installation from this source, and open it.

پیش از انتشار در فروشگاه‌ها، کلید امضا را ثابت کنید: راهنما در `docs/release-notes-2.0.md`.
Pin the signing key before store submission: see `docs/release-notes-2.0.md`.
