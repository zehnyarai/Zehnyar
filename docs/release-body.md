**فایل نصبی اندروید ویزایار** / Visayar universal Android APK

- بسته: `ai.visayar.app` · نسخه ۲٫۳٫۶ (کد نسخه ۳۱)
- همهٔ معماری‌ها در یک فایل: arm64-v8a، armeabi-v7a، x86، x86_64
- فونت وزیرمتن و بانک اطلاعاتی داخل باندل؛ دو ارزیابی نخست رایگان
- هر ارزیابی اضافه ۶۰۰٬۰۰۰ تومان؛ بسته‌های سه، شش و دوازده‌تایی با تخفیف
- پرداخت با کارت‌به‌کارت، ارسال مستقیم فیش به سامانه و فعال‌شدن اعتبار پس از تأیید مدیر
- پرداخت آنلاین فقط در نسخه‌ای کار می‌کند که به نشانی امن سرویس پرداختِ راه‌اندازی‌شده متصل باشد

**نصب:** فایل APK را روی گوشی کپی کنید، اگر پیام «نصب از منابع ناشناس» آمد اجازهٔ نصب را بدهید و فایل را باز کنید.

**Install:** copy the APK to the phone, allow installation from this source, and open it.

Pin the signing key before store submission: see `docs/release-notes-2.0.md`.
