# چک‌لیست انتشار پستینو

## مسدودکننده‌های عرضه عمومی

- [ ] تعیین نام/نام بسته نهایی و دامنه HTTPS واقعی.
- [ ] سرویس بینایی با پشتیبانی عکس و حساب مجاز؛ تست اتصال، هزینه، محدودیت، تأخیر و خروجی نامعتبر.
- [ ] تأیید متخصص پسته ایران و اجرای پروتکل علمی؛ پوشش و عدم‌قطعیت به تفکیک منطقه و عارضه.
- [ ] داده دقیق منطقه/خاک/آب/آزمایش، با منشأ و نسخه؛ هیچ حدس تصویری به‌عنوان اندازه‌گیری اعلام نشود.
- [ ] تأیید هویت/ایمیل، بازیابی رمز، ورود پیامکی در صورت نیاز و مدیریت نشست‌ها/مدیر؛ هیچ رمز پیش‌فرض.
- [ ] قرارداد و رضایت ارسال عکس به سرویس خارجی، سیاست نگهداری/بکاپ و حذف کامل حساب.
- [ ] مهاجرت به زیرساخت چندکاربره پایدار و آزمون بار/امنیت مستقل پیش از مقیاس سراسری.
- [ ] درگاه عملیاتی، تست IRR/تومان، برگشت موفق/ناموفق/Timeout/تکراری، نرخ/صورتحساب/مالیات.
- [ ] گردش بازپرداخت و ابطال اشتراک؛ اصلاح سوابق فقط با رویداد قابل حسابرسی.
- [ ] حذف داده Sandbox از شمارش فروش، کنترل اشتراک آزمایشی و رسیدگی به پرداخت معلق قبل از تغییر محیط.
- [ ] ساخت APK/AAB امضاشده با JDK 21 و SDK 36، تست روی چند گوشی واقعی؛ نگهداری امن کلید امضا.
- [ ] HTTPS App Links و فایل assetlinks با امضای واقعی برای بازگشت پرداخت از مرورگر به اپ.
- [ ] تست دوربین، لغو مجوز، WebView، RTL، اندازه فونت، شبکه ضعیف، پرداخت و ریکاوری پردازش.
- [ ] سیاست‌های بازار/مایکت یا فروشگاه انتخابی، حریم خصوصی عمومی و راه ارتباط پشتیبانی واقعی.

## موارد بعدی

- [ ] تحریریه علمی نسخه‌دار، آرشیو منابع و تاریخ بازبینی؛ به‌روزرسانی صرفاً با تغییر تاریخ کافی نیست.
- [ ] پیامک/Push با رضایت، اتصال آب‌وهوای واقعی با زمان و منبع؛ نه داده ساختگی.
- [ ] آفلاین‌اول، صف ارسال عکس پس از اتصال و ذخیره امن روی دستگاه.
- [ ] ارجاع به کارشناس معتبر، پیگیری نمونه آزمایشگاه و امکان بازخورد اصلاح تشخیص.
- [ ] پایش خطا، مدل/هزینه، drift، هشدارهای امنیتی و تمرین بازیابی بکاپ.

## آنچه فعلاً آزموده شده است

ساخت TypeScript/Vite، آزمون‌های واحد رابط، آزمون‌های API با سرویس خارجی mock، و ۹ جریان مرورگر دسکتاپ/موبایل. Docker، APK، سرویس بینایی/زرین‌پال واقعی و صحت علمی میدانی هنوز آزموده نشده‌اند.
