# نسخه مستقل و رایگان پستینو

در پاسخ به درخواست «فایل نصب بدون راه‌اندازی سرور و بدون پرداخت هزینه»، یک حالت مستقل جدا از نسخه آنلاینِ وابسته به API اضافه شده است. استفاده از آن نیاز به Render، کلید سرویس، حساب اینترنتی، کارت بانکی یا اشتراک ندارد.

- **اندروید:** APK تستِ debug-signed، نام پستینو، شناسه `ir.pestino.app`، اندروید ۷ به بالا. همه فایل‌ها داخل APK هستند؛ سرور یا اینترنت برای شروع لازم نیست. امضای تست برای انتشار در بازار/مایکت یا به‌روزرسانی پایدار نهایی مناسب نیست. native و رفتار گوشی واقعی باید جدا آزمایش شوند.
- **آیفون:** وب‌اپ HTTPS رایگان روی GitHub Pages. در Safari باز می‌شود و با `Share → Add to Home Screen → Add` قابل افزودن است. فایل IPA یا نسخه App Store نیست. IPA بدون امضای معتبر اپل با کپی فایل روی گوشی نصب نمی‌شود. این محیط به امضا/حساب شخصی اپل دسترسی ندارد؛ روش رایگان Personal Team هم نیازمند امضا در ابزار خود مالک است.
- وب‌اپ برای اولین بار و تکمیل cache اینترنت لازم دارد؛ پس از نصب موفق service worker، صفحات و داده‌های محلی بدون اینترنت کار می‌کنند. native اندروید به این cache/میزبانی وابسته نیست.

## امکانات این نسخه

دانشنامه ۱۸ مطلب اولیه، ثبت/ویرایش/حذف باغ، تقویم و یادآور داخل اپ، گرفتن/انتخاب عکس، نگهداری عکس و یادداشت روی دستگاه، جستجو و پشتیبان/بازگردانی JSON. داده واقعی از همان ابتدا خالی است؛ باغ‌ها، پرداخت‌ها یا تشخیص‌های ساختگی ایجاد نمی‌شوند.

**عکس صرفاً ثبت می‌شود، نه تحلیل.** هیچ مدل بینایی، تشخیص آفت/کمبود، امتیاز اطمینان، دوز سم/کود، پرداخت واقعی، حساب سروری، همگام‌سازی بین گوشی‌ها یا اعلان پس‌زمینه در این نسخه وجود ندارد. برای تحلیل هوشمند واقعی همچنان سرویس و اعتبارسنجی جدا لازم است؛ هزینه یا حساب جدیدی از طرف مالک فعال نشده است. دانشنامه تأیید علمی محلی نشده و جای کارشناس/آزمایش نیست.

## حفظ داده‌ها

IndexedDB فقط در همین دستگاه/مرورگر ذخیره می‌شود. حذف برنامه، پاک‌کردن داده‌ها، تغییر مرورگر یا سیاست تخلیه مرورگر می‌تواند آن را حذف کند. از «داده‌ها و پشتیبان» نسخه JSON بگیرید. در اندروید، انتخاب‌گر فایل سیستم محل ذخیره را از خود شما می‌پرسد؛ نیاز به مجوز گسترده حافظه نیست. پشتیبان عکس/باغ/یادآور را شامل می‌شود و رمزگذاری نشده است؛ نشان‌های دانشنامه فقط محلی‌اند. بازگردانی، داده فعلی را جایگزین می‌کند و ادغام نیست.

سقف ایمنی: ۵۰۰ باغ/عکس، ۲۰۰۰ یادآور و حدود ۳۲ مگابایت داده قابل پشتیبان. این سقف پولی نیست. فایل نامعتبر یا خطای ذخیره‌سازی نباید داده موجود را پاک کند. عکس JPEG تازه، حداکثر ضلع ۱۶۰۰ پیکسل ساخته می‌شود تا metadata اصلی EXIF/GPS کپی نشود.

## ساخت و انتشار رایگان

```bash
npm ci
npm run android:standalone
# JDK 21 و SDK 36 لازم‌اند:
cd android && ./gradlew :app:assembleDebug
```

وب‌اپ پروژه:
```bash
VITE_BASE_PATH=/Zehnyar/ npm run build:standalone
```

workflow `pestino-standalone.yml` روی شاخه `arena/e819b607-zehnyar` از runner استاندارد عمومی GitHub استفاده می‌کند. artifact اندروید: `pestino-android-installer`. فقط فایل‌های عمومی دانشنامه/رابط در Pages منتشر می‌شوند؛ هیچ اطلاعات باغ یا عکس کاربر در مخزن یا سایت عمومی بارگذاری نمی‌شود. هیچ تغییر به main یا برنامه‌های قبلی نیاز نیست.


یک APK درخواست‌شده در پوشه `installers/` روی همین شاخه نگه داشته می‌شود تا دانلود آن بدون CDN خارجی ممکن باشد؛ کش، SDK، کلید امضا و هیچ داده کاربر در Git ذخیره نمی‌شود. انتشار دائمی Pages نیاز به فعال بودن Pages در تنظیمات مالک دارد؛ دسترسی فعلی GitHub اجازه ایجاد Pages را نمی‌دهد. تا فعال‌سازی، job انتشار با شرط `PESTINO_PAGES_ENABLED` اجرا نمی‌شود و لینک دائمی آیفون ساخته‌شده تلقی نمی‌شود. پیش‌نمایش موقت، صرفاً امکان آزمون و cache اولیه وب‌اپ را فراهم می‌کند؛ جای سرور دائمی یا IPA نیست.

## نسخه سازگاری ۰.۱.۱

پس از گزارش «App not installed» روی گوشی اندروید ۷ به بالا، ساخت جدید به release غیر-debug تغییر کرده، کتابخانه‌های native به روش قدیمی استخراج می‌شوند و APK با امضای v1/v2/v3 آماده می‌شود. این تغییر **تشخیص قطعی علت خطای گوشی کاربر نیست**؛ به‌علت نبود لاگ PackageInstaller علت دقیق هنوز معلوم نیست. امضا همچنان کلید آزمایشی است، نه کلید ثابت انتشار فروشگاهی؛ داده یا رمز مالک در آن نیست. پیش از تحویل، نصب و شروع Activity در شبیه‌سازهای API 24 و 35 بررسی می‌شود؛ این آزمون جای بررسی گوشی واقعی یا سلامت علمی محتوا را نمی‌گیرد. نسخه ۰.۱.۰ برای سابقه محفوظ می‌ماند و دانلود جدید نام جدا دارد. نسخه‌های با امضای متفاوت را روی یکدیگر نصب نکنید؛ قبل از هر حذف، پشتیبان داده محلی لازم است.
