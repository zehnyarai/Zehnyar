# نصب پستینو — طرح ۰.۲

نام اپ **پستینو / Pestino** و شناسه اندروید **ir.pestino.app** است. دریافت وجه، خرید مدل و میزبان پولی در این کار فعال نشده‌اند. نسخه مستقل نیاز به حساب سروری، کلید سرویس یا راه‌اندازی Render برای بازشدن ندارد؛ **اما کاربر نسخه مستقل را به‌عنوان جایگزین تحلیل واقعی یا IPA قبول نکرده است** و این محدودیتِ باقی‌مانده درخواست است.

## فایل اندروید

فایل جدیدِ ساخته‌شده و تحویل‌شده: `installers/Pestino-0.2.0.apk` با طراحی مرجع، versionCode 3، نسخه release غیر-debug و امضای آزمایشی v1/v2/v3، برای Android 7+ (API 24). ساخت، امضا و نمایش اولیه در شبیه‌سازهای API 24 و 35 موفق شدند. شاخص منبع و مشخصات فایل در `installers/BUILD.txt`، `package-info.txt` و فایل SHA-256 قرار می‌گیرند.

[دانلود اندروید طرح ۰.۲.۰](https://raw.githubusercontent.com/zehnyarai/Zehnyar/arena/e819b607-zehnyar/installers/Pestino-0.2.0.apk)

اندازه واقعی: **۸٬۰۲۰٬۰۴۲ بایت**. SHA-256: `526ec672c19aa8b1893e2d76b41a00bb4fc296a7c42ec0e83a7077a4b755a835`.

ساخت منبع `255c95b90fc510565eafe171c5e0f1ba70e14b38`، تحویل `8dba01d`، اجرای [38159919269](https://github.com/zehnyarai/Zehnyar/actions/runs/38159919269). jobهای apk، install API 24/35 و deliver موفق‌اند و مشاهده عنوان/دکمه در WebView در annotation آنها ثبت شده است. job وب همین اجرا با سیگنال خاتمه **exit 143** متوقف شد؛ نتیجه آن تأیید همه آزمون‌های WebKit نیست. درخواست rerun پذیرفته نشد. به همین دلیل موفقیت همه CI ادعا نمی‌شود و وضعیت cache/فرم‌ها در Chromium بر آزمون محلی مستقل تکیه دارد.

[پوشه فایل‌ها و اطلاعات ساخت](https://github.com/zehnyarai/Zehnyar/tree/arena/e819b607-zehnyar/installers)

APK قبلی **۰.۱.۱** واقعاً ساخته و تحویل شده است: ۷٬۷۱۲٬۴۷۷ بایت، SHA-256 `5e15d39f282ba070960283e841bc67b4112f8777d9259b509c50d7f6b6c832a9`. رابط قدیمی و حالت محلی دارد، نه طرح جدید یا تشخیص تصویر. اجرای [38027403975](https://github.com/zehnyarai/Zehnyar/actions/runs/38027403975) نصب/شروع Activity و نبود crash بومی در API 24/35 را تأیید کرد، نه رابط کامل یا گوشی واقعی. شکست cache وب آن نسخه از نصب native مستقل بود.

آزمون ساخت جدید علاوه بر نصب، وجود بسته، آغاز Activity و نبود native crash، نمایش واقعی عنوان فارسی صفحه و دکمه اسکن در WebView را بررسی می‌کند. اسکرین‌شات و accessibility tree شبیه‌ساز به صورت artifact نگهداری می‌شوند؛ موفقیت این آزمون هنوز جای تست دوربین، انتخاب‌گر فایل، همه امکانات و گوشی واقعی نیست. bundleهای legacy و polyfill برای مرورگر/WebView قدیمی اضافه شده‌اند؛ دستگاه‌هایی با engine بسیار قدیمی ممکن است برای همه قابلیت‌های native به WebView سازگار نیاز داشته باشند.

**امضا کلید ثابت فروشگاهی نیست.** نسخه‌های آزمایشی ممکن است روی هم نصب نشوند. هرگز برای رفع خطای نصب بدون گرفتن پشتیبان، برنامه یا داده‌ها را حذف نکنید. علت دقیق خطای «App not installed» گوشی قبلی بدون لاگ PackageInstaller معلوم نیست.

## آیفون

**IPA امضاشده تولید نشده و میزبانی دائمی HTTPS هم موجود نیست.** پیش‌نمایش و وب‌اپ، فایل نصب بومی iPhone نیستند. افزودن سایت در Safari با `Share → Add to Home Screen → Add` فقط وب‌اپ می‌سازد، و بدون نشانی دائمی نباید معادل تحویل نسخه نهایی آیفون اعلام شود. این محیط به امضا یا ابزار شخصی اپل دسترسی ندارد؛ هیچ هزینه یا حساب جدیدی از مالک خواسته/فعال نشده است.

قابلیت cache عمومی و کار آفلاین در مرورگر Chromium آزموده شده است. مشکل سفیدشدن پس از reload آفلاین، ناشی از `Vary: Origin` فایل module بود و در worker نسخه ۰.۲ اصلاح شد. نخستین بار تا تکمیل cache اینترنت لازم است. آزمون WebKit در CI به بررسی رفتار موتور کمک می‌کند، نه اثبات نصب یا کار همه مدل‌های گوشی آیفون. APK native service worker ندارد و فایل‌های رابطش داخل APK هستند.

## چه چیزهایی در نسخه مستقل کار می‌کنند؟

- طراحی مرجع: منوی افقی، برگ در نشان سبز، زمینه روشن و کارت‌ها؛ صفحه‌های خاک/آب، تجربه، بازار/اقلیم، اعتبار/مدیر و نصب.
- دفتر باغ، یادآور داخل اپ، جستجو و ۲۶ راهنمای آموزشی با منابع و محدودیت‌های جغرافیایی؛ این محتوا تأیید تخصصی محلی نشده است.
- تا چهار عکس مرتبط، زمینه باغ و علائمِ گزارش‌شده، ذخیره/مشاهده/حذف و خروجی متنی پرونده.
- فرم کامل آزمایش خاک و آب با واحد، روش و تاریخ؛ SAR/RSC فقط از اندازه‌گیری‌های واقعاً واردشده، تفسیر محتاطانه آموزشی، ذخیره و تاریخچه.
- تجربه خصوصی روی دستگاه، قیمت و هوا با منبع/تاریخ دستی؛ نه انتشار عمومی یا داده زنده ساختگی.
- پشتیبان/بازگردانی JSON شامل باغ، یادآور، عکس/زمینه، آزمایش، تجربه، قیمت و اقلیم؛ سازگار با پشتیبان‌های قبلی.

**عکس صرفاً ثبت می‌شود، نه تحلیل.** هیچ مدل بینایی داخل این APK نیست. راهنمای دستی به طور مستقل و با نشان «تحلیل تصویر نیست» نمایش داده می‌شود؛ آفت، بیماری، کمبود یا درصد اطمینان از عکس ساخته نمی‌شود. مقدار مواد غذایی، شوری، عامل میکروبی، سلامت ریشه یا آفلاتوکسین از عکس اندازه‌گیری نمی‌شوند. برنامه آموزشی، وعده تولید یا نسخه سم/کود نیست.

مدیریت اعتبار و بانک/رسید در سرور پیاده‌سازی شده، ولی در حالت مستقل و پیکربندی فعلی غیرفعال است. بانک خالی، موجودی صفر و قیمت‌های نمونه مطابق مرجع هستند. اطلاعات بانکی تصاویر کپی نشده‌اند؛ هیچ واریزی انجام ندهید.

## حفظ داده‌ها

IndexedDB فقط در همین دستگاه/مرورگر است؛ رمزگذاری، sync و اعلان پس‌زمینه ندارد. حذف اپ، پاک‌کردن داده‌ها، تغییر مرورگر یا تخلیه مرورگر می‌تواند داده را حذف کند. از «داده‌ها و پشتیبان» JSON بگیرید. انتخاب‌گر فایل اندروید محل ذخیره/خواندن را از کاربر می‌پرسد؛ مجوز گسترده حافظه لازم نیست. پشتیبان رمزگذاری نشده است و بازگردانی جایگزینی است، نه ادغام. نشان‌های دانشنامه صرفاً محلی‌اند.

سقف ایمنی: ۵۰۰ باغ/پرونده عکس و ۵۰۰ رکورد در هر نوع آزمایش/تجربه/قیمت/اقلیم، ۲۰۰۰ یادآور و حداکثر ۳۲ MiB پشتیبان. این سقف پولی نیست. تصویر ورودی حداکثر ۶ MiB، سپس JPEG تازه با حداکثر ضلع ۱۶۰۰ پیکسل ساخته می‌شود و EXIF/GPS اصلی کپی نمی‌شود. پشتیبان نامعتبر یا خطای quota نباید داده فعلی را پاک کند؛ تشخیص، موجودی اعتبار و انتشار عمومی از backup پذیرفته نمی‌شوند.

## ساخت

```bash
npm ci
npm run android:standalone
# JDK 21 و SDK 36؛ ساخت release ابتدا بدون امضا:
(cd android && ./gradlew :app:assembleRelease)
bash tools/sign-compat-apk.sh
```

وب‌اپ مسیر پروژه:

```bash
VITE_BASE_PATH=/Zehnyar/ npm run build:standalone
npm run test:standalone
```

workflow `pestino-standalone.yml` فقط شاخه این جلسه `arena/e819b607-zehnyar` را می‌سازد؛ artifact فایل `pestino-android-installer` است. فقط APK کوچک درخواست‌شده و مشخصات بررسی آن در Git نگهداری می‌شوند؛ SDK، cache، کلید امضا و داده‌های باغدار وارد مخزن نمی‌شوند. Pages تنها فایل‌های عمومی رابط/دانشنامه را می‌گیرد، نه عکس/داده خصوصی. دسترسی فعلی GitHub اجازه ایجاد Pages را نمی‌دهد؛ job انتشار تا فعال‌سازی صریح مالک با شرط `PESTINO_PAGES_ENABLED` اجرا نمی‌شود. main و پروژه‌های قبلی تغییر نمی‌کنند.

جزئیات مسیر بررسی عکس، آزمایش و اعتبار: [طراحی و علم](reference-design-and-science.md). پیش‌شرط علمی: [پروتکل اعتبارسنجی](scientific-validation.md).

## نسخه ۰.۴.۰ — تحلیل عکس و آزمایش با کلید شخصی، بدون سرور

هدف این نسخه پاسخ به نیاز اصلی است: باغدار در باغ عکس می‌گیرد و راهنمای دقیق‌تر می‌خواهد، در حالی که نه سرور داریم و نه اجازه هزینه کردن.

- در «داده‌ها و پشتیبان» مدل و کلید شخصی Google خودتان را ثبت کنید (ساخت کلید: `aistudio.google.com/apikey`)، سپس «آزمون اتصال» را بزنید. تا وقتی این آزمون موفق نشود، دکمه تحلیل عکس فعال نمی‌شود و هیچ نتیجه ساختگی ساخته نمی‌شود.
- تحلیل عکس: از صفحه «اسکن» عکس برگ/میوه/شاخه/تاج را ثبت کنید و «تحلیل عکس» را بزنید. اگر فراخوانی به Google شکست بخورد، عکس و یادداشت شما روی دستگاه می‌مانند و می‌توانید دوباره تلاش کنید.
- آزمایش خاک/آب: در صفحه آزمایشگاه، محاسبات آموزشی مستقل (شوری، SAR/RSC، بُر و...) همیشه کار می‌کنند؛ «دریافت تفسیر هوشمند» با همان کلید شخصی انجام می‌شود.
- کلید در فایل پشتیبان نیست و در APK نصب نمی‌شود؛ فقط در حافظه همان دستگاه می‌ماند. برای تغییر یا پاک‌کردن، همان بخش تنظیمات را ببینید.
- محدودیت‌ها: اینترنت گوشی لازم است و باید به Google دسترسی داشته باشد؛ نتیجه «غربالگری احتمالی» است نه تشخیص قطعی، و اعتبار علمی محلی برای مدل هنوز اندازه‌گیری نشده است. پرداخت، همگام‌سازی، آب‌وهوا و نسخه iPhone همچنان فعال نیستند.

## نسخه ۰.۵.۰ — پنل مدیر مستقل، اتصال مدل و دفتر دریافت

- «پنل مدیر (نسخه مستقل)» جای فرم‌های غیرفعال قبلی را گرفت: ثبت کلید شخصی Google، انتخاب مدل، آزمون اتصال متن‌محور، جدول وضعیت همه بخش‌ها، ثبت کارت مقصد با اعتبارسنجی Luhn و تأیید چشمی، و دفتر دریافتی‌های دستی.
- تحلیل عکس و آزمایش خاک/آب به همین اتصال وصل است؛ تا آزمون موفق، دکمه تحلیل فعال نمی‌شود و هیچ نتیجه ساختگی ساخته نمی‌شود.
- صفحه اعتبار در نسخه مستقل: راهنمای واریز کارت‌به‌کارت با کارت ثبت‌شده و یادآوری صریح «بدون درگاه بانکی و بدون تأیید خودکار».
- وضعیت کامل بخش‌ها: `docs/app-capabilities-fa.md` و همان جدول داخل برنامه در پنل مدیر.

## نسخه ۰.۶.۰ — ورود آسان و رمز مدیر اختیاری

- بدون هیچ شماره همراه، کد پیامکی، ایمیل یا رمزی وارد می‌شوید؛ در نسخه مستقل حتی یک صفحهٔ ورود وجود ندارد.
- پنل مدیر فیلد جداگانهٔ «رمز مدیر» دارد که خودتان تعریف می‌کنید؛ تا وقتی رمز نگذارید، پنل باز است و کسی با رمز ناشناخته بیرون نمی‌ماند. فراموشی رمز = برداشتن قفل با عبارت تأییدی، بدون پاک شدن کارت و دفتر دریافتی.
- ورود مهمان در نسخه آنلاین (`/api/auth/guest`) یک حساب بی‌رمز می‌سازد که همهٔ قابلیت‌های تحلیل را دارد.

## نسخه ۰.۶.۱ — کار با سهمیهٔ رایگان Google

- علت «اتصالی صورت نگرفت» پیدا شد: مدل پیش‌فرض نسخه ۰.۶.۰ (`gemini-3.1-pro-preview`) روی حساب رایگان سهمیه ندارد؛ Google برای آن `429` با `limit: 0` می‌دهد.
- پیش‌فرض به `gemini-2.5-flash` (رایگان و پایدار) تغییر کرد و هیچ مدل پرداختی پیش‌فرض یا جایگزین خودکار نیست.
- دکمه‌های «گرفتن فهرست مدل‌های مجاز این کلید» و «آزمون همهٔ مدل‌های رایگان پیشنهادی» اضافه شد: هر مدل جداگانه امتحان می‌شود و دلیلِ کارنکردنش نوشته می‌شود؛ با یک کلیک انتخاب می‌شود.
- خطاها دلیل واقعی Google را نشان می‌دهند و کلید را در متن خطا افشا نمی‌کنند.
- فهرست رسمی مدل‌های رایگان و پرداختی: `docs/gemini-free-models-fa.md`.

## نسخه ۰.۶.۲ — رفع توقف تحلیل عکس در نسخه مستقل

- گزارش مالک: عکس برگ آپلود شد و دکمهٔ «تحلیل تصویر و بررسی احتمال آفت» فقط پیام «ارسال تصاویر و اطلاعات باغ به سرویس نیاز به تأیید آگاهانه شما دارد» را می‌داد و هیچ تحلیلی انجام نمی‌شد.
- علت: کادر «رضایت آگاهانه» فقط در نسخه سروری نمایش داده می‌شد، ولی شرط تحلیل در هر دو نسخه آن را لازم می‌دانست. در APK هیچ راهی برای تیک‌زدن نبود.
