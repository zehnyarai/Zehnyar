# آسیب‌شناسی استناد گزینشی به قرآن و حدیث — نسخهٔ مقالهٔ علمی–پژوهشی

مقالهٔ مستقل در بازهٔ **۶٬۰۰۰–۷٬۰۰۰ واژه** با ساختار استانداردِ مقالهٔ علمی–پژوهشی.

| شمارش | واژه |
|---|---|
| متنِ مقاله + چکیدهٔ فارسی + فهرست منابع | **۶٬۸۲۸** |
| کلِ فایل، با چکیدهٔ انگلیسی | **۶٬۹۹۴** |
| متنِ اصلی، بدونِ چکیده و منابع | ۶٬۳۲۳ |

## ساختار

۱. مقدمه و طرح مسئله (بیان مسئله، پرسش اصلی و فرعی، فرضیه، روش)
۲. پیشینهٔ پژوهش و خلأ پژوهشی
۳. چارچوب مفهومی: گزینش / گزینش‌گری / آنچه استناد گزینشی نیست
۴. مبنای نظری: حجیتِ ظهور، سه‌گانهٔ قرینه، «قاعدهٔ وابستگیِ دلالت»
۵. گونه‌شناسی: چهار خانواده، پانزده گونه (جدول)
۶. قرآن، خودْ نقدِ استناد گزینشی است (+ خطبهٔ ۴۰ نهج‌البلاغه)
۷. پیامدها: شش سطح
۸. علل: پنج لایه
۹. سه مصداقِ تحلیلی
۱۰. از تشخیص تا درمان
۱۱. آزمونِ شش موضعِ رقیب
۱۲. نتیجه‌گیری (شش نتیجهٔ اصلی)
فهرست منابع · چکیدهٔ انگلیسی

## فایل‌ها

- `selective-citation-article.md` — متنِ کامل (منبعِ اصلی)
- `selective-citation-article.html` — نسخهٔ چاپی/خواندنی، راست‌به‌چپ، با فونتِ جاسازی‌شده (Ctrl+P → PDF)
- `selective-citation-article.docx` — نسخهٔ قابلِ ویرایش در Word
- `source/part1.md … part3.md` — بخش‌های منبع که با `cat` به فایلِ نهایی می‌پیوندند

## بازسازیِ خروجی‌ها

```bash
cd docs/papers/article
cat source/part1.md source/part2.md source/part3.md > selective-citation-article.md
python3 ../build_article.py selective-citation-article.md selective-citation-article.html
python3 ../build_docx.py  selective-citation-article.md selective-citation-article.docx  # نیازمند python-docx
```

## یادداشتِ ارجاعات

ارجاعات در سطحِ «اثر + باب/موضوع» داده شده‌اند و شمارهٔ صفحهٔ حدسی ذکر نشده است؛ این، خود بخشی از مدعای مقاله است (پرهیز از «حجیت‌نماییِ ارجاع»). پیش از چاپ، تطبیق با نسخهٔ معیّنِ چاپی لازم است.
