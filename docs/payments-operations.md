# راهنمای راه‌اندازی پرداخت و پنل مدیریت

دو ارزیابی نخست برای هر نصب رایگان‌اند و قیمت خرید تکی هر ارزیابی ۶۰۰٬۰۰۰ تومان است. بسته‌های چندتایی تخفیف دارند:

| بسته | مبلغ | تخفیف نسبت به خرید تکی |
|---|---:|---:|
| یک ارزیابی | ۶۰۰٬۰۰۰ تومان | بدون تخفیف |
| سه ارزیابی | ۱٬۵۰۰٬۰۰۰ تومان | ۱۷٪ |
| شش ارزیابی | ۲٬۷۰۰٬۰۰۰ تومان | ۲۵٪ |
| دوازده ارزیابی | ۴٬۸۰۰٬۰۰۰ تومان | ۳۳٪ |

## راه‌اندازی امن مدیر

پنل در مسیر `/admin/payments` قرار دارد و فقط با نام کاربری و گذرواژه‌ای که مدیر سامانه از پیش برای سرور تنظیم کرده وارد می‌شود. گذرواژه به شکل درهم‌سازی‌شده نگهداری می‌شود؛ کلیدهای هوش مصنوعی و اطلاعات کارت مقصد با کلید رمزگذاری سرور رمز می‌شوند.

۱. از ریشهٔ مخزن، وابستگی‌ها را نصب کنید و ابزار ساخت تنظیمات اولیه را اجرا کنید:

```sh
python -m pip install -r requirements.txt
python tools/setup_admin.py
```

ابزار نام کاربری و گذرواژه می‌گیرد و سه مقدار محرمانه تولید می‌کند: `VISAYAR_ADMIN_USERNAME`، `VISAYAR_ADMIN_PASSWORD_HASH` و `VISAYAR_ENCRYPTION_KEY`. این مقادیر را در بخش اسرار محیطی میزبان ذخیره کنید؛ آن‌ها را در مخزن، فایل عمومی، APK یا پیام‌رسان قرار ندهید. مقدار کلید رمزگذاری را جداگانه و امن پشتیبان بگیرید. اگر این کلید گم شود، کلید هوش مصنوعی و کارت‌های ذخیره‌شده دیگر قابل بازیابی نیستند.

۲. در بخش اسرار میزبان، موارد زیر را تنظیم کنید:

```sh
VISAYAR_ADMIN_USERNAME='نام مدیر'
VISAYAR_ADMIN_PASSWORD_HASH='خروجی درهم‌سازی ابزار راه‌اندازی'
VISAYAR_ENCRYPTION_KEY='کلید رمزگذاری تولیدشده'
PAYMENTS_DATA_DIR='/مسیر/پایدار/داده'
```

۳. API را روی دامنهٔ عمومی دارای گواهی معتبر HTTPS و فضای ذخیره‌سازی پایدار راه‌اندازی کنید. سپس پنل را در `https://دامنه-شما/admin/payments` باز کنید؛ پس از ورود، از بخش تنظیمات، کلید Gemini و مشخصات کارت مقصد را وارد کنید. کلید Gemini هرگز در این پنل دوباره به‌صورت کامل نمایش داده نمی‌شود و فقط در سرور برای `/api/advisor` استفاده می‌شود. مقادیر ذخیره‌شده در پایگاه دادهٔ SQLite رمزگذاری‌شده‌اند.

در صورت نیاز می‌توانید مشخصات کارت را از راه اسرار محیطی `PAYMENT_CARD_NUMBER`، `PAYMENT_CARD_HOLDER` و `PAYMENT_BANK_NAME` نیز تنظیم کنید. مقدار ذخیره‌شده از پنل بر مقدار محیطی اولویت دارد. برای فعال‌شدن خرید، کارت شانزده‌رقمی، نام دارنده، بانک و پیکربندی مدیر باید موجود باشند.

## رسیدها و تأیید پرداخت

مشتری از اپ شمارهٔ همراه، شناسهٔ پیگیری و تصویر رسید را ارسال می‌کند. مدیر باید رسید را با تراکنش بانکی تطبیق دهد و سپس آن را در پنل تأیید یا رد کند. فقط تأیید مدیر اعتبار را به همان نصب اضافه می‌کند؛ ثبت شناسهٔ پیگیری تکراری پذیرفته نمی‌شود. تمام مسیرهای مدیریتی API به ورود پنل و نشست امن نیاز دارند؛ احراز هویت با توکن ثابت پشتیبانی نمی‌شود.

پایگاه داده و رسیدها در `PAYMENTS_DATA_DIR` نگهداری می‌شوند. پشتیبان رمزگذاری‌شده و منظم تهیه کنید. پیش از فروش عمومی، فرایند بازیابی پشتیبان و انقضای نشست را آزمایش کنید. ورود پس از هشت تلاش ناموفق از همان نشانی شبکه برای پانزده دقیقه محدود می‌شود؛ نشست مدیر پس از دوازده ساعت پایان می‌یابد.

## اتصال اپ

در نسخهٔ فعلی `apiBaseUrl` اپ خالی است. برای فعال‌شدن پرداخت در APK باید API عمومی HTTPS را در `mobile/app.json` تنظیم، برنامه را با نشانی همان API بسازید و نسخهٔ تازه منتشر کنید. این مخزن به‌تنهایی میزبان تولیدی یا درگاه بانکی را فراهم نمی‌کند. پرداخت دستی است و نیازمند تأیید انسانی است.
