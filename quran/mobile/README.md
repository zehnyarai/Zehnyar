# نسخهٔ موبایل قرآن‌پژوهه

این پوشه یک پوستهٔ بومی Android/WebView برای قرآن‌پژوهه است. در زمان ساخت، رابط وب، پیکرهٔ آفلاین و چارچوب پژوهش به داخل APK کپی می‌شوند. نسخهٔ جاری ۱٫۱۹٫۰ است و نشانِ کتابِ گشوده با نقطهٔ نورِ پژوهش در وب و Android یکپارچه شده است. شناسهٔ نصب این نسخه `ai.zehnyar.reader` است تا با نمونه‌های آزمایشی قدیمی تداخل امضا نداشته باشد.

## رفتار نسخهٔ Android

- **آفلاین:** پیکرهٔ کاملِ ۶٬۲۳۶ آیه، کتابخانهٔ هر ۱۱۴ سوره، annotation تحریری برای همهٔ آیات، چهار متنِ تفسیریِ منبع‌دار و ۲۱ پروندهٔ داستانیِ آیه‌لنگر داخل APK هستند. پروندهٔ هر سوره چهار تب مستقل برای نمای کلی، محورهای واژگانی، واژگان کم‌تکرار و نقل‌های منبع‌دار دارد؛ کنار هر نقل نسخه، بازهٔ آیه و پیوندِ منبع ثبت می‌شود. سه تفسیر حجیم با انتخاب جداگانهٔ کاربر و هر بار یکی خوانده می‌شوند تا مصرف حافظهٔ گوشی کنترل شود. annotationهای افزوده‌شده پیش‌نویس‌اند و به بازبینی تخصصی نیاز دارند.
- **شفافیت پژوهشی:** در حالت بی‌اتصال نیز نتیجه‌ها فقط برچسبِ تطابق واژگانی یا پیوند مرتبط می‌گیرند. نقل‌های تفسیری با نام اثر، نسخه، انتساب و پیوند همراه‌اند؛ کاتالوگ نیز وضعیت متن‌های واردشده و منابعِ هنوز واردنشده را جدا نشان می‌دهد. یادداشت هر بخش جداگانه در حافظهٔ همان دستگاه ذخیره می‌شود. تحلیل‌های داستانی «متن‌محور» یا «پرسش کاربرد» برچسب می‌خورند، نه تفسیرِ بی‌منبع.
- **آنلاین:** API اختیاری FastAPI برای تحلیل و خروجی Markdown در استقرار سرور پروژه در دسترس است؛ این پوستهٔ اولیه برای مسیرهای اصلیِ پژوهش به آن وابسته نیست.

## ساخت محلی

نیازمند JDK 17 و Android SDK با API 35 است:

```bash
gradle -p mobile/android assembleDebug
```

فایل خروجی:

```text
mobile/android/app/build/outputs/apk/debug/app-debug.apk
```

برای ساخت آزمایشی، workflow **قرآن‌پژوهه Android APK** در `.github/workflows/zehnyar-apk.yml` را از تب Actions اجرا کنید و فایلِ نام‌گذاری‌شدهٔ `QuranPajoohe-1.19.0.apk` را از artifact `quran-pajoohe-android-apk` بگیرید. نام نمایشی هنگام نصب «قرآن‌پژوهه» است؛ انتشار در Releases جداگانه و پیش‌فرضاً خاموش است. APK دیباگ برای نصب شخصی مناسب است؛ برای Google Play باید کلید امضا و build انتشار مستقل ایجاد شود.
