# نسخهٔ موبایل قرآن‌پژوهه

این پوشه یک پوستهٔ بومی Android/WebView برای قرآن‌پژوهه است. در زمان ساخت، رابط وب، پیکرهٔ آفلاین و چارچوب پژوهش به داخل APK کپی می‌شوند. نسخهٔ جاری ۱٫۱۵٫۱ است و نشانِ کتابِ گشوده با نقطهٔ نورِ پژوهش در وب و Android یکپارچه شده است. شناسهٔ نصب این نسخه `ai.zehnyar.reader` است تا با نمونه‌های آزمایشی قدیمی تداخل امضا نداشته باشد.

## رفتار نسخهٔ Android

- **آفلاین:** پیکرهٔ کاملِ ۶٬۲۳۶ آیه با ترجمهٔ فولادوند/Tanzil، کتابخانهٔ ۱۱۴ سوره و ۲۱ پروندهٔ داستانیِ آیه‌لنگر داخل APK هستند. پروندهٔ پایهٔ شش‌فیلدی در این checkout ۱٬۰۹۰ آیه را پوشش می‌دهد. لایهٔ جداگانهٔ ده‌فیلدیِ تازه، ۸:۵۱–۷۵ و توبه ۹:۱–۲۸ را (۵۳ آیه) زیرِ رکوردِ همان آیه‌ها نگه می‌دارد؛ فیلدها شامل مقایسه با کتاب مقدس، گفتمان هدایتی قرآن، شبهات، علوم جدید، قرائات، مبانی فلسفی، زبان‌شناسی، تحلیل گفتمان انتقادی، زمینهٔ تاریخی و بلاغت/نظم‌اند. در این ۵۳ آیه، اعتبارسنجی ۲۵ فیلدِ افزودهٔ کامل، ۱۸۲ ناقص و ۳۲۳ نیازمندِ پژوهش می‌شمارد؛ این شمارها فیلدند، نه آیه. در ۹:۲۸ شش فیلدِ پایه هرکدام دست‌کم پنج بند دارند و از ده فیلدِ افزوده نه‌تا دست‌کم پنج بند دارند؛ `modernSciences` پس از جست‌وجوی محدود خالی و `needs-research` است. بنابراین سورهٔ توبه هنوز کامل نیست و ۹:۲۹–۱۲۹ به این لایه افزوده نشده‌اند. متنِ کاملِ التفسير الميسر محلی است؛ منابعِ بدون فایل محلی فقط با وضعیت و پیوند معرفی می‌شوند.
- **شفافیت پژوهشی:** در حالت بی‌اتصال نیز نتیجه‌ها فقط برچسبِ تطابق واژگانی یا پیوند مرتبط می‌گیرند. نقل‌های تفسیری با نام اثر، نسخه، انتساب و پیوند همراه‌اند؛ کاتالوگ نیز وضعیت متن‌های واردشده و منابعِ هنوز واردنشده را جدا نشان می‌دهد. یادداشت هر بخش جداگانه در حافظهٔ همان دستگاه ذخیره می‌شود. تحلیل‌های داستانی «متن‌محور» یا «پرسش کاربرد» برچسب می‌خورند، نه تفسیرِ بی‌منبع.
- **آنلاین:** API اختیاری FastAPI برای تحلیل و خروجی Markdown در استقرار سرور پروژه در دسترس است؛ این پوستهٔ اولیه برای مسیرهای اصلیِ پژوهش به آن وابسته نیست.

## ساخت محلی

نیازمند JDK 17 و Android SDK با API 35 است:

```bash
gradle -p mobile/android assembleDebug
```

فایل خروجی:

```text
mobile/android/app/build/outputs/apk/debug/app-debug.apk
```

برای انتشار قابل اعتماد، از workflow `Build Android APK` در GitHub Actions استفاده کنید. APK دیباگ برای نصب شخصی مناسب است؛ برای Google Play باید کلید امضا و build انتشار مستقل ایجاد شود.
