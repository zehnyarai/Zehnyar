# منابع متنی و انتساب

این پوشه نسخهٔ محلیِ داده‌های مورد نیاز برای جست‌وجوی آفلاین «قرآن‌پژوهه» را نگه می‌دارد.

- **متن عربی:** `quran-uthmani.json` از پروژهٔ [risan/quran-json](https://github.com/risan/quran-json)، مسیر منبع `data/tanzil/uthmani.json`، متن Tanzil Uthmani. فایلِ بالادستی دست‌نخورده نگه داشته شده است؛ برای نمایشِ شماره‌گذاریِ آیه، پیشوندِ بسمله‌ای که این بسته در آیهٔ اولِ سوره‌های ۲–۸ و ۱۰–۱۱۴ به‌صورتِ سرعنوان تکرار می‌کند از پیکرهٔ نمایشی حذف می‌شود. بسملهٔ فاتحه ۱:۱ و بسملهٔ درونِ آیهٔ نمل ۲۷:۳۰ حفظ می‌شوند؛ توبه نیز پیشوندِ بسمله ندارد. این قاعده در `tools/build_offline_corpus.py` و بارگذارِ API مستند و آزمون شده است؛ شرایط و انتسابِ Tanzil همچنان باید رعایت شوند.
- **ترجمهٔ فارسی:** `quran-fa-fooladvand.json`، شناسهٔ ترجمه `fa.fooladvand`، ترجمهٔ **محمدمهدی فولادوند**. فایل با حفظ متن و شماره‌گذاری از [Kristories/quran](https://github.com/Kristories/quran/tree/master/fixtures/fa/fooladvand) در commit `3a796d5d7f80c80b83adae5b39affcec2aeb426c` وارد شده است؛ README آن مخزن Tanzil را منبع اولیه معرفی می‌کند. SHA-256 فایل منبع: `8d97ebdd52a1e1d326e74533e475f131bc8f1626e8e490b9d61150f92f407215`. شناسه و مشخصات پین‌شده در `TRANSLATION_SOURCE.json` نیز ثبت شده است.
- **فرادادهٔ سوره‌ها:** `chapters.json` از مسیر `data/tanzil/chapters.json` پروژهٔ مذکور.

ترجمهٔ فولادوند تابع شرایط منبع Tanzil است: **استفادهٔ غیرتجاری، حفظ انتساب و پیوند به منبع**. برنامه دیوار پرداخت ندارد و هر کمک مالی اختیاری است؛ پرداخت هیچ محتوای پولی یا مزیت دسترسی ایجاد نمی‌کند. برای بررسی نسخه و شرایط منبع به [Tanzil](https://tanzil.net/trans/) مراجعه کنید.
