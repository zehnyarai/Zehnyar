# نصب قرآن‌پژوهه روی اندروید

قرآن‌پژوهه اکنون دو راه اجرا دارد. هر دو از یک پیکرهٔ محلیِ ۶٬۲۳۶ آیه برای جست‌وجوی پایه استفاده می‌کنند.

## راه اول — PWA نصب‌پذیر با پژوهش پیشرفته

این راه برای استفادهٔ کامل پیشنهاد می‌شود: بازیابی موضوعی، شبکهٔ لایه‌ای، مسیرهای روایی، گراف و گزارش Markdown همگی فعال می‌مانند.

1. برای حالت آفلاین و نصب بدون هشدار Play Protect، می‌توانید GitHub Pages مخزن را فعال کنید؛ سپس نشانی `https://zehnyarai.github.io/Zehnyar/` را در Chrome اندروید باز کنید. workflow `Deploy installable PWA` فایل‌های لازم را منتشر می‌کند.
2. یا مخزن را از طریق **Render** به‌عنوان یک Web Service متصل کنید. فایل `render.yaml` آماده است.
3. پس از بازشدن نشانی HTTPS در Chrome اندروید، از منوی Chrome گزینهٔ **Install app** یا **Add to Home screen** را بزنید.
4. اپ مانند یک برنامهٔ مستقل روی گوشی باز می‌شود و shell و پیکرهٔ آفلاین را cache می‌کند.

## راه دوم — فایل APK از GitHub

APK قرآن‌پژوهه برای نصب شخصی Android آماده شده است. در حالت بی‌اتصال، متن عربی و ترجمهٔ فارسی، هشت مسیر جست‌وجوی پژوهشی، نقشهٔ ۱۱۵ مسیر موضوعیِ واژگانی، کتابخانهٔ ۱۱۴ سوره، پروندهٔ همهٔ ۶٬۲۳۶ آیه و چهار متن تفسیریِ منبع‌دار در گوشی در دسترس‌اند. نسخهٔ ۱٫۱۸٫۰ است؛ ترجمهٔ پایهٔ فارسی در همهٔ صفحه‌ها و حالت آفلاین، ترجمهٔ فولادوند با شناسهٔ Tanzil `fa.fooladvand` است و استفاده از آن غیرتجاری است؛ منبع و شرایط در `data/ATTRIBUTION.md` آمده‌اند. پروندهٔ سوره‌ها چهار فیلدِ منبع‌محور و ارجاع‌پذیر دارد و سه تفسیر حجیم با انتخاب هر منبع و هر بار یکی بارگیری می‌شوند تا مصرف حافظهٔ گوشی کنترل شود. در همهٔ صفحه‌ها «یادداشت من / پیشنهاد من» در دسترس است: یادداشت شخصی محلی می‌ماند و پیشنهاد عمومی با شناسهٔ آیه و شاهدِ دقیق از همان آیه برای بازبینی فرستاده می‌شود؛ در حالت بی‌اتصال، پیش‌نویسِ پیشنهاد همراهِ ارجاع و شاهد روی دستگاه نگه داشته می‌شود. سرنخ‌های زبانهٔ «پژوهش در آیه» نیز قابل‌ردیابی‌اند. پرونده‌های annotation تازه پیش‌نویس‌اند و نیازمند بازبینی تخصصی هستند. موضوع‌ها و پیوندهای آن شاهدِ واژگانی‌اند و «کاربست امروز» در پروندهٔ قصه، پرسش پژوهشی است نه حکم یا تفسیرِ بی‌ارجاع.

1. پس از push تغییرات این نسخه، workflow **Zehnyar Quran APK** در GitHub Actions خودکار APK را می‌سازد و آن را به‌صورت artifact بارگذاری می‌کند. برای ساخت دستی، همان workflow را از تب **Actions** اجرا کنید؛ انتشار در Releases پیش‌فرضاً خاموش است.
2. پس از پایان موفق، صفحهٔ اجرای workflow را باز کنید و از بخش **Artifacts**، فایل `zehnyar-android-apk` را دریافت کنید؛ داخل آن `app-debug.apk` قرار دارد. انتشار یا به‌روزرسانیِ release آزمایشی فقط با انتخاب صریحِ `publish_release` در اجرای دستی انجام می‌شود.
3. هنگام نصب، Android ممکن است اجازهٔ نصب از این مرورگر/مدیر فایل را بخواهد؛ فقط پس از اطمینان از دانلود از مخزن خودتان آن را تأیید کنید.
4. پس از اجرای APK، هشت مسیر جست‌وجو، دو کتابخانه و چهار بخشِ مطالعهٔ هر آیه را بدون نیاز به اتصال بررسی کنید. برای API تحلیلی و خروجی Markdown، نسخهٔ وب را از استقرار HTTPS پروژه باز کنید.

## یادداشت انتشار

`app-debug.apk` برای نصب شخصی و آزمایش است. برای انتشار در Google Play باید کلید امضای اختصاصی، build انتشار (`release`) و سیاست حریم خصوصی مستقل آماده شود.
