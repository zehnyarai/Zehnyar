# ذهن‌یار — پژوهش موضوعیِ شاهد-محور در قرآن

«ذهن‌یار» یک وب‌اپ فارسی و راست‌به‌چپ برای شروع پژوهش موضوعی در قرآن است. کاربر واژه یا موضوعی مانند `عدالت`، `رحمت`، `علم` یا یک واژهٔ عربی وارد می‌کند و ابزار، مسیر بازیابی را به‌صورت قابل بازبینی نمایش می‌دهد:

- **شاهد مستقیم:** آیه‌هایی که عبارت جست‌وجوشده در متن عربی یا ترجمهٔ فارسی آن‌ها پیدا شده است.
- **پیوند واژگانی موضوعی:** فقط برای چند موضوعِ بازبینی‌شده، واژه‌های هم‌خانوادهٔ کوچک و قابل مشاهده به جست‌وجو افزوده می‌شوند. برچسب هر شاهد در رابط کاربری مشخص است.
- **سیاق خطی:** همسایه‌های چند آیهٔ نخست به‌صورت جداگانه نشان داده می‌شوند تا آیه از بافت نزدیکش جدا خوانده نشود.
- **گراف مسیر بازیابی:** گرهٔ پرسش، واژه‌های شاهد و آیه‌های نتیجه را به هم وصل می‌کند. این گراف نمایشِ رابطهٔ بازیابی است، نه تفسیر قطعی.

این محصول عمداً پاسخ مولدِ بدون منبع تولید نمی‌کند و **فتوا، ترجمهٔ جدید یا تفسیر نهایی** نیست. برای داوری معنایی، شأن نزول، ناسخ و منسوخ، اختلاف قرائات، قواعد اصولی و تفاسیر معتبر باید با پژوهشگر/متخصص گفت‌وگو شود.

## اجرا

```bash
python -m venv .venv
source .venv/bin/activate  # در ویندوز: .venv\Scripts\activate
pip install -r requirements.txt
uvicorn main:app --host 0.0.0.0 --port 8000 --reload
```

سپس `http://localhost:8000` را باز کنید. مستندات تعاملی API در `/docs` در دسترس است.

## API

### `POST /api/analyze`

```json
{
  "query": "عدالت",
  "limit": 12,
  "include_context": true
}
```

خروجی شامل شمارش سطح‌های شواهد، آیه‌های عربی و فارسی، برچسب واژهٔ شاهد، سیاق، پرسش‌های پژوهشی، روش و دادهٔ گراف است.

دیگر مسیرها:

- `GET /api/health` — سلامت پیکره و تعداد آیات
- `GET /api/meta` — موضوع‌ها و واژه‌های گسترش‌دهندهٔ شفاف
- `GET /api/verse/{surah}/{ayah}` — یک آیه با ارجاع

## معماری و استاندارد پژوهش

- **پیکرهٔ محلی:** همهٔ ۶٬۲۳۶ آیه در شروع برنامه از JSON بارگذاری و برای جست‌وجوی عربی/فارسی نرمال‌سازی می‌شوند؛ برنامه برای نتایج اصلی به کلید مدل زبانی یا سرویس بیرونی متکی نیست.
- **نرمال‌سازی محافظه‌کارانه:** حرکات، گونه‌های الف/ی/ک و فاصله‌های نامرئی برای بازیابی یکدست می‌شوند؛ متن نمایشی بدون این تغییرها باقی می‌ماند.
- **تفکیک لایه‌ها:** عبارت مستقیم و توسعهٔ واژگانی هیچ‌گاه در یک برچسب ادغام نمی‌شوند.
- **توسعهٔ واژگانی قابل ممیزی:** نگاشت موضوع‌ها در ثابت `TOPICS` در `main.py` کوچک، صریح و قابل بازبینی است. افزودن هر حوزهٔ جدید باید با متخصص زبان عربی و مطالعات قرآنی بازبینی شود.
- **حریم خصوصی:** پرسش برای کارکرد اصلی از مرورگر به همان سرور ارسال می‌شود و در برنامه ذخیره نمی‌شود.

## داده و انتساب

پوشهٔ `data/` شامل متن عربی، ترجمهٔ فارسی و فرادادهٔ سوره‌هاست. جزئیات کامل در [`data/ATTRIBUTION.md`](data/ATTRIBUTION.md) و مجوز بسته در [`data/LICENSE-quran-json-CC-BY-SA-4.0.txt`](data/LICENSE-quran-json-CC-BY-SA-4.0.txt) آمده است.

- متن عربی: **Tanzil Uthmani**، به‌صورت لفظ‌به‌لفظ، از پروژهٔ [Quran JSON](https://github.com/risan/quran-json)
- ترجمهٔ فارسی: **QuranEnc — Persian, Ihsan Elahi Zaheer**، از همان پروژه
- بستهٔ Quran JSON: **CC BY-SA 4.0**؛ هنگام بازنشر شرایط منابع بالادستیِ Tanzil و QuranEnc نیز باید رعایت شوند.

## گام‌های پیشنهادی برای نسخهٔ پژوهشی بعدی

1. افزودن صرف و نحو، ریشه‌شناسی و برچسب نقش دستوری با دادهٔ دارای مجوز روشن.
2. وارد کردن ارجاعات تفاسیر منتخب با صفحه/جلد دقیق و نمایش اختلاف دیدگاه‌ها، نه یک جمع‌بندی یگانه.
3. افزوده‌شدن بردارهای معناییِ چندزبانه در کنار بازیابی واژگانی، با نمایش دلیل رتبه‌بندی و امکان خاموش‌کردن آن.
4. پنل پژوهشگر برای بازبینی و نسخه‌بندی نگاشت‌های موضوعی و پیوندهای گراف.
5. آزمون‌های تخصصی برای جلوگیری از خلط مشتقات، اشتراک لفظی و نتایج خارج از سیاق.
