# ذهن‌یار — Zehnyar

سامانه هوشمند ارزیابی و راهنمای مهاجرت، به‌همراه اپلیکیشن اندروید.

Intelligent immigration assessment platform with an Android super-app.

| | |
|---|---|
| **پوشش داده** | ۱۵ کشور · ۵۸ مسیر ویزا · ۵۰ شغل استاندارد · ۸ آزمون زبان |
| **Data coverage** | 15 countries · 58 visa routes · 50 standard occupations · 8 language tests |
| **آخرین استعلام رسمی / Last official verification** | مهر ۱۴۰۵ / اکتبر ۲۰۲۶ — `2026-10-25` |
| **نسخه داده / Dataset version** | `2.0.0` |
| **بسته اندروید / Android package** | `ai.zehnyar.app` |

## ۱. معماری / Architecture

```
.
├── shared/
│   ├── dataset.json          # منبع یگانه داده (تولیدشده) — single source of truth
│   └── engine-fixtures.json  # خروجی مرجع موتور پایتون برای تست هم‌ارزی
├── tools/
│   ├── dataset_lib.py        # زبان توصیفی قواعد امتیازدهی
│   ├── countries_a.py        # بسته کشور ۱: کانادا، استرالیا، بریتانیا، آلمان، آمریکا، هلند، نیوزیلند
│   ├── countries_b.py        # بسته کشور ۲: فرانسه، ایتالیا، اسپانیا، سوئد، دانمارک، ترکیه، امارات، عمان
│   ├── occupations.py        # بانک مشاغل با کد NOC و ANZSCO
│   ├── build_dataset.py      # تولید + اعتبارسنجی + بومی‌سازی ارقام فارسی
│   ├── sync_mobile_data.js   # همگام‌سازی داده با باندل اپ
│   ├── make_fixtures.py      # تولید فیکسچر از موتور پایتون
│   ├── parity_check.js       # اثبات یکسانی موتور پایتون و جاوااسکریپت
│   ├── check_i18n.js         # تضمین purity زبان فارسی در CI
│   └── android_prepare.js    # پیکربندی امضای release برای APK
├── backend/app/
│   ├── main.py               # FastAPI (نسخه وب/شریک)
│   └── engine/engine.py      # موتور ارزیابی مرجع (Python)
├── mobile/
│   ├── App.js                # ناوبری، فونت، تم
│   └── src/
│       ├── core/engine.js    # همان موتور، آینه‌شده در JS (اجرای آفلاین روی گوشی)
│       ├── core/data.js      # بانک اطلاعاتی باندل‌شده
│       ├── screens/          # خانه، ویزارد ۸ مرحله‌ای، نتایج، مقصد، مشاور، تنظیمات
│       ├── components/       # کیت رابط کاربری + نمودارهای راداری/حلقه‌ای
│       ├── i18n/             # دیکشنری دوزبانه بدون هیچ واژه لاتین در فارسی
│       └── assets/           # فونت وزیرمتن + آیکون‌ها
└── .github/workflows/        # CI + ساخت APK امضاشده
```

**اصل طراحی:** همه محاسبات ارزیابی روی گوشی انجام می‌شود. اپلیکیشن بدون اینترنت کامل کار می‌کند، حساب کاربری نمی‌خواهد و هیچ داده‌ای ارسال نمی‌کند. بک‌اند فقط برای نسخه وب، شرکا و بازبینی قواعد است.

## ۲. اجرای سریع / Quick start

### اپلیکیشن موبایل

```bash
cd mobile
npm ci
npm start           # Expo dev server
npm test            # تست رابط کاربری
```

### ساخت APK امضاشده (بدون نیاز به ابزار محلی)

GitHub → Actions → **Android release APK** → *Run workflow*. پس از حدود ۱۵ دقیقه:

- فایل نصبی در بخش **Releases** با نام `Zehnyar-2.0.0-universal.apk`
- و در **Artifacts** همین اجرا (`zehnyar-release-apk`)

برای ساخت پایدار، فایل keystore تولیدشده (artifact با نام `zehnyar-release-keystore`) را دانلود و به‌صورت Secret با نام `ANDROID_KEYSTORE_BASE64` ذخیره کنید تا همه بیلدهای آینده با یک کلید امضا شوند (شرط به‌روزرسانی اپ در فروشگاه‌ها).

### بک‌اند

```bash
python3 -m venv .venv && .venv/bin/pip install -r requirements-dev.txt
python3 tools/build_dataset.py
.venv/bin/uvicorn main:app --reload      # http://127.0.0.1:8000/docs
.venv/bin/python -m pytest backend/tests -q
```

## ۳. موتور ارزیابی / Assessment engine

هر مسیر ویزا با یک مجموعه **قاعده توصیفی** (`criteria`) و یک مجموعه **شرط ورودی سخت** (`gates`) تعریف می‌شود. هیچ امتیازی در کد hard-code نشده است؛ همه از `shared/dataset.json` می‌آید.

**دسته‌های امتیاز:** سن، تحصیلات، زبان (چهار مهارت جدا)، سابقه کار، تمکن مالی، سازگاری.

**قواعد پشتیبانی‌شده:** `age_band`, `education_rank`, `language_skills`, `language_best`, `experience_band`, `flag`, `salary_band`, `numeric_band`, `funds_ratio`, `adaptability`, `spouse`.

**شرط‌های ورودی:** `age_gate`, `language_gate`, `experience_gate`, `points_gate`, `funds_gate`, `education_gate`, `flag_gate`, `salary_gate`, `investment_gate`, `remote_income_gate`, `custom_points`.

**تبدیل نمره زبان:** نمره خام هر آزمون با جدول رسمی هر آزمون به **CLB** (معیار مشترک کانادا) و سپس به CEFR تبدیل می‌شود. مثال IELTS: شنیداری ۸٫۰ → CLB ۹، خواندن ۷٫۰ → CLB ۹.

**فرمول شانس (شفاف و قابل بازبینی):**

```
readiness = امتیاز کسب‌شده / سقف امتیاز مسیر
اگر شرط ورودی برطرف‌نشده باشد:
    chance = 5 + 26 × readiness × max(0.35, 1 − 0.12 × تعداد شرط‌ها)
در غیر این صورت:
    chance = 100 × readiness × (0.62 + 0.38 × selectivity)
    اگر امتیاز به حدنصاب نرسد: chance ×= 0.72
chance در بازه ۳٪ تا ۹۶٪ محدود می‌شود.
```

`selectivity` سختی رقابتی همان مسیر است (مثلاً استعداد جهانی بریتانیا ۰٫۳۰ و ویزای تحصیلی ۰٫۷۸). فرمول هیچ‌گاه ۱۰۰٪ اعلام نمی‌کند، چون هیچ ارزیابی‌ای تضمین پذیرش نیست.

**هم‌ارزی دو موتور:** `tools/parity_check.js` روی شش پرونده نمونه، ۱۴۸۲ مقایسه عددی بین موتور پایتون و موتور جاوااسکریپت انجام می‌دهد و باید صفر اختلاف بدهد. در CI اجرا می‌شود.

## ۴. دوزبانگی و purity فارسی

- زبان فارسی ۱۰۰٪ فارسی است: نه واژه لاتین، نه رقم لاتین. `tools/check_i18n.js` این را در CI می‌شکوکند و ساخت را متوقف می‌کند.
- ارقام در تمام متن‌های فارسی (امتیاز، درصد، مبلغ) به شکل ۰۱۲۳۴۵۶۷۸۹ نمایش داده می‌شوند.
- چیدمان راست‌به‌چپ به‌صورت سراسری با `useDirection()` مدیریت می‌شود (نه استایل‌های پراکنده).
- فونت **وزیرمتن** در چهار وزن داخل باندل قرار دارد و بدون اینترنت بارگذاری می‌شود.
- یک استثنای عامدانه: نام کدهای استاندارد بین‌المللی شغل (`NOC 21231`، `ANZSCO 261313`) و نام آزمون‌های لاتین در صفحه انتخاب مدرک زبان با حروف لاتین نمایش داده می‌شوند، چون خودِ کد شناسه بین‌المللی است و ترجمه آن گمراه‌کننده خواهد بود.

## ۵. اعتبار منابع / Source credibility

هر کشور در بانک اطلاعاتی سه چیز را حمل می‌کند:

1. **مرجع رسمی** (`official.authorityFa/En`) — مثلاً IRCC، Home Affairs، BAMF، USCIS، IND.
2. **درگاه دولتی** (`official.portal`) — لینک مستقیم و قابل باز شدن در اپ.
3. **تاریخ آخرین استعلام** (`official.lastVerified`) — یکسان برای کل نسخه داده: `2026-10-25`.

هزینه‌ها دو سطح اعتبار دارند: `verified: true` (از جدول رسمی همان سال) و `verified: false` (بازه تقریبی/مرجع غیررسمی). در رابط کاربری با نشان «تأییدشده» و «تقریبی» تفکیک می‌شوند.

نمونه ارقام تأییدشده ۲۰۲۶ که در داده استفاده شده است:

| کشور | مورد | مقدار |
|---|---|---|
| کانادا | هزینه بررسی پرونده متقاضی اصلی | ۹۹۰ دلار کانادا |
| کانادا | حق اقامت دائم (RPRF) | ۶۰۰ دلار کانادا |
| کانادا | تمکن مالی تک‌نفر / خانواده چهارنفره | ۱۵٬۲۶۳ / ۲۸٬۳۶۲ دلار کانادا |
| استرالیا | هزینه درخواست ۱۸۹ / ۱۹۰ | ۶٬۱۳۵ / ۶٬۱۴۰ دلار استرالیا |
| بریتانیا | آستانه حقوق کارگر ماهر | ۴۱٬۷۰۰ پوند |
| بریتانیا | هزینه درخواست تا ۳ سال / خدمات سلامت سالانه | ۸۱۹ / ۱٬۰۳۵ پوند |
| آلمان | آستانه کارت آبی / مشاغل کمبود نیرو | ۵۰٬۷۰۰ / ۴۵٬۹۳۴٫۲۰ یورو |
| هلند | آستانه ماهانه ۳۰ سال و بالاتر / زیر ۳۰ | ۵٬۹۴۲ / ۴٬۳۵۷ یورو |

توجه: نرخ ارز مرجع در `shared/dataset.json` تنها برای یکسان‌سازی مقایسه استفاده می‌شود و نرخ معاملاتی نیست.

## ۶. حریم خصوصی و امنیت

- بدون ثبت‌نام، بدون سرور، بدون ردیابی.
- پاسخ‌ها و نتایج در `AsyncStorage` همان گوشی ذخیره می‌شوند و با «حذف همه اطلاعات» پاک می‌شوند.
- اپ هیچ مجوز حساس اندروید (دوربین، میکروفون، مخاطبین، موقعیت) درخواست نمی‌کند.
- در بک‌اند، کلید مدل زبانی فقط از متغیر محیطی خوانده می‌شود و هیچ کلیدی در مخزن نیست.
