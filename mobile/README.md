# نسخهٔ موبایل ذهن‌یار

این پوشه یک پوستهٔ بومی Android/WebView برای ذهن‌یار است. در زمان ساخت، رابط وب، پیکرهٔ آفلاین و چارچوب پژوهش به داخل APK کپی می‌شوند. شناسهٔ نصب این نسخه `ai.zehnyar.reader` است تا با نمونه‌های آزمایشی قدیمی تداخل امضا نداشته باشد.

## رفتار نسخهٔ Android

- **آفلاین:** پیکرهٔ ۶٬۲۳۶ آیه، هشت مسیر جست‌وجوی پژوهشی، نقشهٔ ۱۱۵ مسیر موضوعیِ واژگانی، کتابخانهٔ ۱۱۴ سوره، دو متن تفسیریِ منبع‌دار برای هر آیه و ۲۱ پروندهٔ داستانیِ آیه‌لنگر داخل APK هستند.
- **شفافیت پژوهشی:** در حالت بی‌اتصال نیز نتیجه‌ها فقط برچسبِ تطابق واژگانی یا پیوند مرتبط می‌گیرند. چهار بخشِ هر کارت آیه با کلید لفظی و گزیدهٔ بدون‌ویرایش از منبع تفسیری نمایش داده می‌شوند؛ دو تفسیر متن، نسخه و پیوندِ دقیق خود را دارند. فهرستِ ده تفسیر مقایسه‌ایِ درخواستی نیز فقط با وضعیتِ مجوز/نسخه نمایش داده می‌شود و متنِ واردنشده به آن‌ها نسبت داده نمی‌شود؛ تحلیل‌های داستانی نیز «متن‌محور» یا «پرسش کاربرد» برچسب می‌خورند، نه تفسیرِ بی‌منبع.
- **آنلاین:** API اختیاری FastAPI برای تحلیل و خروجی Markdown در استقرار سرور پروژه در دسترس است؛ این پوستهٔ اولیه برای مسیرهای اصلیِ پژوهش به آن وابسته نیست.

## ساخت محلی

نیازمند JDK 17 و Android SDK با API 35 است:

```bash
gradle -p mobile/android assembleDebug
```

فایل خروجی:

```text
mobile/android/app/build/outputs/apk/debug/app-debug.apk
```

برای انتشار قابل اعتماد، از workflow `Build Android APK` در GitHub Actions استفاده کنید. APK دیباگ برای نصب شخصی مناسب است؛ برای Google Play باید کلید امضا و build انتشار مستقل ایجاد شود.
