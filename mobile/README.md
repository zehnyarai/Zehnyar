# نسخهٔ موبایل ذهن‌یار

این پوشه یک پوستهٔ بومی Android/WebView برای ذهن‌یار است. در زمان ساخت، رابط وب، پیکرهٔ آفلاین و چارچوب پژوهش به داخل APK کپی می‌شوند.

## رفتار نسخهٔ Android

- **آفلاین:** جست‌وجوی پایهٔ عبارت در متن عربی و ترجمهٔ فارسیِ ۶٬۲۳۶ آیه روی خود دستگاه کار می‌کند.
- **آنلاین:** در PWAِ بازشده از سرور FastAPI، یا پس از واردکردن آدرس HTTPS سرور در APK، بازیابی موضوعی، گراف لایه‌ای، مسیرهای روایی، گزارش کامل و سایر تحلیل‌های پیشرفته فعال هستند.
- APK عمداً یک تفسیرگر محلیِ بدون منبع نیست؛ در حالت بی‌اتصال، فقط قابلیت‌های قابل اتکا و واژگانی را نشان می‌دهد.

## ساخت محلی

نیازمند JDK 17 و Android SDK با API 35 است:

```bash
gradle -p mobile/android assembleDebug
```

فایل خروجی:

```text
mobile/android/app/build/outputs/apk/debug/app-debug.apk
```

برای انتشار قابل اعتماد، از workflow `Build Android APK` در GitHub Actions استفاده کنید. APK دیباگ برای نصب شخصی مناسب است؛ برای Google Play باید کلید امضا و build انتشار مستقل ایجاد شود.
